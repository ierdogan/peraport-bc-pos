# Peraport POS for Business Central

**TR:** Microsoft Business Central için mağaza kasa (POS) add-on çözümü.  
**EN:** Retail Point of Sale (POS) add-on solution for Microsoft Business Central.

## Özellikler / Features
- POS oturumu yönetimi / POS session management
- Çoklu ödeme tipi (Nakit, Kart, Kupon) / Multiple payment types
- Barkod ile ürün arama / Barcode product lookup
- Varyant desteği (Beden/Renk) / Variant support (Size/Color)
- Terminal/Kasa yönetimi / Terminal management

## Geliştirici Kurulum / Developer Setup
1. VS Code + AL Language extension kur
2. `.vscode/launch.json` dosyasında `<TENANT_ID>` kısmını sandbox tenant ID'nle değiştir
3. `Ctrl+Shift+P` → `AL: Download Symbols`
4. `F5` ile sandbox'a deploy et

## Nesne Aralığı / Object ID Range
